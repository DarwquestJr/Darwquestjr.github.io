What is 3D Printing and how it all works

There are a few different types of 3D printing. The 2 main types are Fused Deposition Modeling (FDM) and Stereolithography (SLA).These are most commonly known as extrusuion printing and resin based printing. Extrusion based printing is like a robotic glue gun, it takes hards plastic filament and heats it up pushing it out a small hole to create layers that build up to form a 3D object. Resin based printing uses a liquid resin that is cured by a light source, usually UV light, to harden the resin layer by layer to create a 3D object. Both types of printing require a digital 3D model to be created using computer-aided design (CAD) software or 3D scanning. The digital model is then sliced into thin layers using slicing software, which generates the instructions for the 3D printer to follow. The printer then builds the object layer by layer according to these instructions.
